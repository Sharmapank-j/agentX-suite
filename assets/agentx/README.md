# AgentX App Assets

**Package:** `com.agentx`  
**Module:** `:app`  
**Role:** General-purpose assistant.

This directory contains branding assets and may contain historical APK artifacts.

**Important:** The historical `v1.0.0` APK predates the inference safety repair. It is not evidence of current source behavior and must not be treated as a validated offline-inference build. Local generation is disabled until a genuine shared GGUF runtime is integrated.

## Branding assets
- `ic_launcher_foreground.xml` — neural X foreground vector.
- `ic_launcher_background.xml` — dark background vector.
